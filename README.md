## Getting Started
This section will guide you through the process of setting up **quadtree-visualiser**.

### Installation
First, create a Python virtual environment:
```sh
python -m venv .venv
```

Activate the virtual environment:
```sh
source .venv/bin/activate
```

Install the required dependencies
```sh
pip install -r requirements.txt
```

Run the project:
```sh
python main.py
```
